## 어려웠던 점 3가지와 해결
1.화면 크기 변화에 따라 영화 카드가 유연하게 배치되도록 미디어 쿼리를 구성하는 과정이 꽤 까다로웠습니다. 크기를 줄일 때마다 카드가 찌그러져 여러 번 수정했는데, CSS Grid와 min-width 미디어 쿼리를 단계별로 조합하여 모바일 1열부터 데스크톱 4열까지 깔끔한 반응형 구조를 완성했습니다.
2.내가 원하는 글자나 칸에만 디자인을 적용하는 과정이 정말 헷갈리고 어려웠습니다. 클래스이름이 겹치거나 구조가 꼬여서 엉뚱한 곳이 자꾸 바뀌곤 했는데, 개발자 도구로 하나씩 확인하며 이름을 깔끔하게 정리해 해결했습니다.
3.상세 페이지에서 포스터와 줄거리를 양옆으로 나란히 놓는 게 뜻대로 안 되어 애를 먹었습니다. 작은 화면에서는 위아래로 차곡차곡 쌓이게 하고, 넓은 화면에서는 양옆 2단으로 나뉘도록 코드를 수정해 깨끗하게 완성했습니다.
